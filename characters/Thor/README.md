# Thor — scans à fournir

Même flux que le Forge Master (vérification par photos AVANT tout encodage) :

1. **Board du héros** (recto complet, lisible) → à la racine de ce dossier
2. **Leaflet/carton de règles du perso** (les 2 faces si imprimées) → racine
3. **Cartes** → dans `cards/` :
   - les cartes PROPRES au héros (upgrades + actions uniques)
   - PAS les communes (déjà scannées dans `characters/common/`)
   - cartes en plusieurs exemplaires : nommer `Nom 1.jpg`, `Nom 2.jpg`, … (comme les Ore du Forgemaster)
4. Noter ici toute divergence board/carte constatée (ça a déjà attrapé des erreurs : Furnace 4B, Gauntlets BBBAA)

PV/CP de départ : 50 PV et 2 CP pour tous (norme du jeu, pas besoin de le confirmer).
Seuls les JETONS de départ varient (ex. BW 3 Covert, HH la Tête) : visibles sur le board/leaflet.
