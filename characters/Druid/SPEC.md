# DRUID — spec vérifiée (scans user 2026-07-06, rulings user confirmés)

Dé : 1-3 **Claw** (A) · 4-5 **Paw** (B) · 6 **Nature** (C). Départ : 50 PV, 2 CP, **Druid Form**, 0 jeton.

## Formes (overlay ; changées UNIQUEMENT par Shape Shift)
- **Druid** : à la conclusion de ton tour, gagne Regenerate ② (1v1 : soi-même).
- **Cat** : si ta Offensive Roll Phase se conclut par une Attaque : **+2 dégâts et inflige Wound** (Attack Modifier).
- **Bear** : défense renforcée (voir Thick Hide).

## Jetons
- **Shape Shift** (Unique, cap 2) : dépensable À TOUT MOMENT → Transform Bear / Cat / retour Druid. Non retirable/transférable autrement.
- **Regenerate** (Positif, cap 2, jeton 2 faces) : à TON upkeep — face ② : soigne 2, flip sur ① ; face ① : soigne 1, retiré. Gain d'un ② au cap → peut flipper un ① en ②.
- **Wound** (Négatif, cap 2) : l'affligé prend 1 dégât à SON upkeep, puis lance 1d6 : 4-6 → retire le jeton (par jeton).
