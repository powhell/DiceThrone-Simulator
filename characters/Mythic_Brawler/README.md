# Mythic Brawler — scans à fournir

Même flux que les persos précédents (vérification par photos AVANT tout encodage) :

1. **Board du héros** (recto complet, lisible) → dans `board/`
2. **Leaflet/carton de règles du perso** (les 2 faces si imprimées) → dans `leaflet/`
3. **Cartes** → dans `cards/` :
   - les cartes PROPRES au héros (upgrades + actions uniques)
   - PAS les communes (déjà scannées dans `characters/common/`)
   - cartes en plusieurs exemplaires : nommer `Nom 1.jpg`, `Nom 2.jpg`, …
4. Noter ici toute divergence board/carte constatée

PV/CP de départ : 50 PV et 2 CP pour tous (norme du jeu).
Seuls les JETONS de départ varient : visibles sur le board/leaflet.
