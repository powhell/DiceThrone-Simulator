# Règles générales (setup, phases, deck)

Dépose ici les captures d'écran de dice-throne.rulepop.com (ou toute autre source) pour les
règles générales qui ne sont pas sur une carte physique : HP/CP/main de départ, CP gagné par
tour, taille max de la main, nombre de cartes pigées par tour, structure des phases, etc.

Claude Code les lira avec le tool `Read` pour remplir `engine-ts/src/sim/data/config.ts`
(remplace les valeurs `*_PLACEHOLDER`).
